# Car Parts & Accessories Shop

**UFCFC3-30-1 Introduction to OO Systems Development**

A Java Swing GUI application for managing stock items in a car parts and accessories shop.  
Demonstrates inheritance, polymorphism, encapsulation, and a fully functional GUI.

## How to Run
1. Import the project into Eclipse
2. Run `ShopGUI.java` as Java Application
3. Use the dropdown to create different stock items and test add/sell/change price operations

## Main Classes
- `StockItem.java` – Base class
- `NavSys.java` – Subclass (Navigation System)
- `CarTire.java`, `CarBattery.java`, `EngineOil.java` – Additional subclasses
- `ShopGUI.java` – Main graphical user interface
- `TestNavSys.java` & `TestPolymorphism.java` – Test classes for inheritance and polymorphism

## Features Implemented
- All required methods (`addStock`, `sellStock`, `toString`, etc.)
- Inheritance and method overriding
- Polymorphism with dynamic method binding
- User-friendly Swing GUI
